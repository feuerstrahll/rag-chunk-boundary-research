# Mistral: выполнение заблокировано API, оценок нет

27.10.2026. Установлены запрошенные `mistralai==3.5.0` и
`python-dotenv==1.2.4`. Ключ использован из защищённого временного файла вне
проекта; в результаты он не включён. Получить оценки достаточности не удалось.

| Модель | Ответ API | Валидных оценок |
|---|---|---:|
| `mistral-large-latest` | HTTP 403 | 0 |
| `mistral-medium-2604` | 6 последовательных HTTP 429 с backoff | 0 |
| `mistral-small-2603` | 6 HTTP 429; лимит запросов в минуту = **0** | 0 |

Для Small каждый ошибочный ответ содержит:

```text
x-ratelimit-limit-req-minute: 0
x-ratelimit-remaining-req-minute: 0
```

Это нулевой разрешённый лимит, а не просто отсутствие оставшихся запросов.
Увеличение интервала между запросами само по себе этот лимит не исправит.
Причина назначения нулевого лимита из ответа API не установлена; состояние
подписки и платежей не проверялось. Общие числа бесплатного тарифа не доказывают,
что конкретному ключу сейчас разрешены запросы.
Персональные лимиты доступны в Admin Panel → API → Limits, согласно
[официальной документации Mistral](https://docs.mistral.ai/admin/billing-usage/usage-limits).

В сумме сделано 13 отклонённых транспортных попыток первого слепого запроса.
Это **не 13 оценок** и не сравнение трёх моделей. Ни одного ответа судьи нет.
Пакетное задание не создавалось: разрешение на сетевой batch-запуск было отклонено.
Дальнейшие повторы при явно нулевом лимите отключены в адаптере.
