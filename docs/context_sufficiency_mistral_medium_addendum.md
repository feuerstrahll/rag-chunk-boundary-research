# Доступная модель судьи: Mistral Medium

Зафиксировано до получения первой валидной оценки. Вызов указанного в примере
пользователя `mistral-large-latest` завершился HTTP 403; валидных оценок — 0.
Models API показывает 53 доступных идентификатора, включая
`mistral-medium-2604`, но не `mistral-large-latest`.

В рамках исходного требования «одна доступная LLM» для полного эксперимента
выбрана доступная версия **mistral-medium-2604**. Large и Medium не сравниваются;
все экспериментальные оценки должны быть получены одной моделью Medium.
Неуспешная попытка Large остаётся отдельным артефактом и в знаменатель не входит.
Остальные настройки, rubric, контексты и анализ сохраняются по Mistral-дополнению:
temperature=0, random_seed=2026, JSON object, max_tokens=400, 386 контекстов.

Запуск использует фиксированный версионный идентификатор, а не `latest`.
Права на модель и её фактическое имя проверяются ответами API.
