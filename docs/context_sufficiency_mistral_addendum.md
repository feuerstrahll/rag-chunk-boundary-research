# Дополнение к протоколу: Mistral

Зафиксировано до первого вызова судьи 27.10.2026 после предоставления пользователем
доступа к Mistral API. Прежние пакеты подготовки и протокол не перезаписываются.

Судья: запрошенный пользователем `mistral-large-latest`, temperature=0,
random_seed=2026, JSON object, max_tokens=400. Фактическое имя из каждого ответа
сохраняется; смена имени внутри запуска останавливает эксперимент. Alias `latest`
может меняться между запусками, поэтому воспроизводимость опирается также на
сырые ответы и фактический идентификатор модели.

Запускаются все 386 ранее подготовленных слепых запросов из
`context_sufficiency_20261027_v2`, без изменения их содержания или порядка.
Контексты, rubric, разделение QA, Sufficiency Rate, парный bootstrap и план
проверки 12 оценок остаются прежними. Генерация ответов на QA не добавляется.

Небольшой SDK-адаптер использует существующие `messages`, `validate_judgment` и
`analyze`. Установлены запрошенные `mistralai` и `python-dotenv` во временную среду;
версии фиксируются в запуске. Credentials читаются из временного файла вне
проекта и в артефактах не сохраняются.

Транспортное уточнение до запуска: минимальный интервал 1,2 с, SDK retries
отключены. Только HTTP 429 и 5xx повторяются до пяти раз с ограниченным backoff;
эти события записываются отдельно. Полученный JSON, даже спорный или ошибочный,
повторно не запрашивается. Усечение, некорректный JSON или неподдерживаемые
параметры по-прежнему останавливают запуск. Это не повторная выборка меток.

Документация API: [Mistral Chat Completion](https://docs.mistral.ai/api/endpoint/chat).
