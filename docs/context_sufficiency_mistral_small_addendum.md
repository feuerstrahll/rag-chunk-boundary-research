# Доступность судьи: попытка Mistral Small

Зафиксировано до получения первой валидной оценки. Large вернула HTTP 403;
Medium — шесть последовательных HTTP 429 с backoff до 30 с. Ни одной оценки
не получено. Пакетный сетевой запуск отклонён до исполнения; batch job не создан.

В рамках условия «одна доступная LLM» проверяется `mistral-small-2603`, включённая
в доступный ключу список моделей. Если сервис принимает запросы, вся выборка
оценивается только этой версией. Неуспешные транспортные попытки других моделей
не становятся оценками или дополнительным экспериментальным сравнением.

Температура 0, random_seed=2026, max_tokens=400, JSON rubric, бюджет контекста и
193 пары вопросов остаются прежними. Вызовы последовательные с интервалом
не менее двух секунд. Код дополнительно сохраняет только связанные с лимитами
заголовки ошибочных ответов (`ratelimit` и `retry-after`), без credentials.
