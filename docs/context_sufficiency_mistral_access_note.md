# Результат проверки Mistral API — 27.10.2026

Пользователь предоставил доступ к Mistral API; `mistralai==3.5.0` и
`python-dotenv==1.2.4` установлены во временную среду. Исходные контексты и
rubric из пакета `context_sufficiency_20261027_v2` не изменены.

Ни одна из транспортных попыток не вернула оценки. Large: HTTP 403. Medium:
шесть HTTP 429. Small: шесть HTTP 429 с явными заголовками
`x-ratelimit-limit-req-minute: 0` и `x-ratelimit-remaining-req-minute: 0`.
Для Small это нулевой разрешённый лимит запросов в минуту, а не свидетельство
слишком короткой паузы между запросами. Причина назначения нулевого лимита
из доступных ответов не установлена; платёжный статус аккаунта не проверялся.

Пакетный запуск не был исполнен: разрешение на сетевую команду отклонено.
Batch job не создавался. Неиспользованный batch-адаптер удалён из новых изменений.

Последующее уточнение транспорта: если сервер явно указывает нулевой лимит
числа запросов, HTTP 429 больше не повторяется. Обычные временные HTTP 429
при положительном/неизвестном лимите и HTTP 5xx по-прежнему допускают
ограниченный backoff. Неполученные оценки не подменяются другими метками.

Лимиты конкретной организации/модели нужно проверить в
[Mistral Usage and limits](https://docs.mistral.ai/admin/billing-usage/usage-limits).
Публичные ориентировочные числа бесплатного тарифа не заменяют фактические
заголовки API. Изменение аккаунта или его лимитов не выполнялось.
