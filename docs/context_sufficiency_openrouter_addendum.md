# Судья через OpenRouter — 27.10.2026

Пользователь предоставил доступ к OpenRouter и указал `openai/gpt-4o`.
После неуспешных попыток Mistral валидных оценок всё ещё 0, поэтому в сравнении
модели не смешиваются. Все 386 слепых запросов оценивает только GPT-4o.

Температура 0, seed=2026, JSON object, max_tokens=400. Провайдер фиксируется:
`only=[openai]`, `allow_fallbacks=false`, `require_parameters=true`.
Фактические model/provider/system_fingerprint из сырых ответов сохраняются;
изменение model/provider останавливает запуск. Нулевая температура и seed не
гарантируют побитовую воспроизводимость серверного inference.

Используются прежний rubric, порядок и 386 текстов из
`context_sufficiency_20261027_v2`; входные hashes проверяются. Подготовленные
контексты, retrieval, chunking, индексы, покрытие и план анализа не меняются.
Вопрос и контекст — единственные данные в сообщении судье; gold и название
метода отсутствуют. Один небольшой HTTP-адаптер переиспользует `messages`,
`validate_judgment`, `analyze`; новый SDK не устанавливается.

Вызовы последовательные, минимальный интервал 1,2 с. Только транспортные HTTP
429/5xx допускают до пяти повторов с backoff; явный нулевой лимит, некорректный
JSON и усечение останавливают запуск. Полученные оценки повторно не выбираются.
Ключ читается из защищённого временного файла вне проекта, не сохраняется в
артефактах и будет удалён после запуска.
